# Como Compartilhar Pastas no Gimie

## 📱 Funcionalidade

Agora você pode compartilhar suas pastas de produtos com amigos! Quando alguém acessa via link compartilhado e clica em "Shop Now", será solicitado o download do app antes de acessar os produtos.

## 🎯 Como Compartilhar uma Pasta

Existem **duas formas** de compartilhar uma pasta:

### Opção 1: Pelo Perfil (Lista de Pastas)

1. Vá para a aba **Perfil**
2. Na lista de pastas, clique nos **três pontinhos** (⋮) da pasta que deseja compartilhar
3. Selecione **"Compartilhar pasta"** no menu
4. O link será **copiado automaticamente** para a área de transferência
5. Cole e envie o link para seus amigos!

### Opção 2: Dentro da Pasta

1. Abra a pasta que deseja compartilhar
2. No topo da tela, clique no **ícone de compartilhar** (🔗)
3. O link será **copiado automaticamente** para a área de transferência
4. Cole e envie o link para seus amigos!

## 💡 Formato do Link

O link gerado tem este formato:
```
https://gimie.site/?shared=true&folder=Nome%20da%20Pasta&user=seu_user_id
```

**Exemplo real:**
```
https://gimie.site/?shared=true&folder=Roupas%20de%20Ver%C3%A3o&user=abc123xyz
```

## 🎬 O que Acontece Quando Alguém Usa o Link?

1. **Pessoa clica no link compartilhado**
   - Abre o site Gimie no navegador
   - Vê uma página bonita com header personalizado

2. **Vê o Header Atraente**
   - 👤 **Foto do usuário** (ou iniciais se não tiver foto)
   - 📝 **@username** do dono da pasta
   - 📥 **Botão "Baixar Gimie"** destacado
   - 🔐 **Botão "Entrar"** para quem já tem conta

3. **Navega pela pasta compartilhada**
   - Vê todos os produtos da sua pasta
   - Pode visualizar imagens, preços e nomes
   - Scroll suave com header que permanece visível

4. **Clica em "Shop Now" em algum produto** ou **"Baixar Gimie"**
   - 🚨 **MODAL DE DOWNLOAD APARECE!**
   - Modal bonito pedindo para baixar o app
   - Opções: App Store ou Play Store

5. **Usuário baixa o app**
   - Clica em um dos botões de download
   - É direcionado para a loja correspondente
   - Baixa o app Gimie completo

## ✅ Confirmação Visual

Quando você compartilha uma pasta, aparece uma mensagem verde:

```
✓ Link copiado! Compartilhe com seus amigos
```

Esta mensagem confirma que o link está pronto para ser enviado.

## 🔒 Privacidade

- ✅ Você só pode compartilhar **suas próprias pastas**
- ✅ O botão de compartilhar só aparece nas **suas pastas** (não nas de outros usuários)
- ✅ Qualquer pessoa com o link pode **visualizar** a pasta
- ❌ Visitantes **não podem editar** ou adicionar produtos
- ❌ Visitantes **não podem fazer compras** sem baixar o app

## 📱 Compatibilidade

- **Web**: Gera links de compartilhamento
- **App iOS**: URLs apontam para App Store brasileira
- **App Android**: URLs apontam para Play Store

## 🎨 Design

### Header da Página Compartilhada
- **Avatar circular** com foto do usuário ou iniciais
- **@username** destacado em roxo
- **Botão "Baixar Gimie"** grande e proeminente
- **Botão "Entrar"** para usuários existentes
- Header que permanece visível ao fazer scroll

### Botão no Perfil
- Menu de três pontos (⋮)
- Opção com ícone de compartilhar roxo
- "Compartilhar pasta" como primeira opção

### Botão na Pasta
- Ícone de compartilhar (🔗) roxo
- Posicionado no canto superior direito
- Visível apenas nas suas pastas

### Modal de Download
- Design moderno e limpo
- Ícone de sacola de compras
- Dois botões grandes e coloridos:
  - **Preto** para App Store (com logo da Apple)
  - **Verde** para Play Store (com logo do Android)
- Opção "Agora não" para fechar

## ⚠️ Observações Importantes

1. **Login Necessário**: Você precisa estar logado para compartilhar pastas

2. **Link Permanente**: O link funciona enquanto:
   - Sua conta existir
   - A pasta existir
   - Os produtos estiverem salvos

3. **Se Renomear a Pasta**: Links antigos ainda funcionarão se você renomear a pasta

4. **Se Apagar a Pasta**: Links param de funcionar

5. **Produtos Privados**: Todos os produtos da pasta compartilhada são visíveis publicamente via link

## 🆘 Problemas?

**Link não copia?**
- Verifique se está logado
- Tente novamente
- Recarregue a página

**Botão de compartilhar não aparece?**
- Só aparece nas **suas** pastas
- Não aparece nas pastas de outros usuários

**Modal não aparece para visitantes?**
- Verifique se acessou com `?shared=true` na URL
- Teste em uma aba anônima
